Meu Investidor

Projeto desenvolvido como parte do desafio da DIO, utilizando Microsoft Excel.

Objetivo:

-Criar uma ferramenta para simular investimentos em Fundos Imobiliários (FIIs).

Funcionalidades:

-Simulação de aportes mensais.

-Cálculo de dividendos.

-Projeção de patrimônio acumulado.

-Planejamento financeiro de longo prazo.

Ferramenta utilizada:

-Microsoft Excel.
